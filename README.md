Sistema de Control de Inventario ABB
Proyecto integrador de Estructura de Datos - ITSX.
Giovanni Hernandez Rodriguez
 
Descripcion
Aplicacion en Java basada en consola que simula el control de inventario utilizando un Arbol Binario de Busqueda, ordenando los productos alfabeticamente por su nombre mediante el metodo compareTo.
Funcionalidades
  a Insercion: Agrega productos evitando duplicados y ordenandolos alfabeticamente.
  b Busqueda: Localiza productos mediante la tecnica de Divide y Venceras.
  c Eliminacion: Da de baja registros manejando los tres casos, nodo hoja, un hijo y dos hijos con sucesor inorden.
  d InOrder: Muestra el inventario completo ordenado.
  e Salir: Cierra la aplicacion.
Ejecucion
  Abrir el proyecto en el entorno de desarrollo.
  Ejecutar la clase principal Main.java.
  Interactuar en la consola con las opciones del menu.
